# Курс "Основы машинного обучения"

- Результат: теоретическое и практическое знание алгоритмов машинного обучения и смежных тем

- Группы делятся на команды не более 2-х человек

- Команды готовят и выступают с презентациями по выбранным темам

- Все презентации и индивидуальные задания сохраняются в едином [git-репозитории](https://github.com/job-modelware-ru/bml-2026).

## Командная работа

Команда выбирает тему и проводит презентацию по ней.

Презентация должна содержать ответы на вопросы:
- зачем это нужно / какая задача решается?
- пример решения на языке Python
- численный пошаговый простой пример
- описание альтернативных вариантов и сравнение с ними

Оценка командной деятельности - коллективная.

Все презентации сохраняются в git-репозитории. Например, для темы **Метод решающих деревьев** команды **01** структура директорий следующая:
- 01-Метод решающих деревьев\
    - src\ - исходный код, который используется в презентации
    - Метод решающих деревьев.pdf - pdf-версия презентации
    - readme.md - содержание каталога

По презентациям могут быть заданы вопросы, на которые нужно дать ответ. Вопросы можно задавать, как на занятиях, так и после них.

## Индивидуальная работа

Индивидуальная деятельность связана с самостоятельным выполнением задачи и 5-10 минутной презентацией результатов.

Исходный код сохраняются в git-репозитории (место указывается куратором)

## Правила выставления оценок

За курс можно получить максимум 100 баллов, которые соответствуют оценкам:
- 91-100 - отлично
- 71-90 - хорошо
- 51-70 - удовлетворительно
- менее 51 - неудовлетворительно

Баллы начисляются:
- презентации: от 0 до 50
    - на все вопросы, заданные на презентации должен быть дан ответ (сразу, на последующих занятиях, в чате)
- вопросы на лекциях: от 0 до 10 (один вопрос от 0 до 2 баллов)
    - в ТГ после занятия все те, кто задавал вопросы пишут их в формате:
        - ФИО, <тема презентации>
        - 1. <формулировка первого вопроса>
        - 2. <формулировка второго вопроса>
        - ...
    - 0 - вопрос на уточнение уже сказанного, т.е. реально вопросом не является.
    - 1 - вопрос, на который прямого ответа в презентации нет, но ответ может быть логически выведен из имеющихся данных
    - 2 - вопрос, который актуален для данной темы, но не освещен в презентации
- индивидуальные задания: от 0 до 40

Обязательным условием получения положительной оценки является прохождение онлайн-курса по машинному обучению.
