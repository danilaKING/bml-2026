### Каталог `src/`

| Файл | Что внутри |
| --- | --- |
| `LinearRegression.py` | Собственная реализация модели линейной регрессии через класс `MyLinearRegression` |
| `simple-ex.py` | Обучает `LinearRegression` на трёх парах «площадь квартиры — цена», выводит свободный член и коэффициент площади, рассчитывает цену для квартиры площадью 60 м² и отображает график с исходными точками, линией регрессии и прогнозом |
| `many-params.py` | Обучает регрессию на данных о доставке по трём признакам: расстояние, количество товаров и час пик; выводит свободный член, коэффициенты, MAE на тестовой части и прогноз времени доставки для нового заказа |
| `teach-test.py` | Делит 12 пар «бюджет — продажи» на обучающую и тестовую выборки, обучает линейную регрессию, выводит коэффициент, свободный член, MAE и R², затем прогнозирует продажи для бюджета 52 |
| `run_all.py` | По очереди запускает `simple-ex.py`, `teach-test.py` и `many-params.py` |
| `requirements.txt` | Зависимости |


## Запуск кода

```bash
cd src
pip install -r requirements.txt

python run_all.py            # все скрипты по порядку
python simple-ex.py          # или любой скрипт по отдельности
