### Каталог `src/`

| Файл | Пункт | вывод |
| --- | --- | --- |
| `common.py` | — | Общая палитра, стиль графиков |
| `01_why_cv.py` | 1 | Эмпирическая ошибка и ошибка на контрольной выборке в зависимости от сложности модели; дисперсия оценки по 300 случайным разбиениям (размах 11.2 п.п.); зависимость дисперсии оценки и качества модели от доли контрольной выборки |
| `02_python_example.py` | 2 | `kfold_cross_val` — реализация процедуры без сплиттеров scikit-learn (расхождение с `cross_val_score` равно нулю); `cross_val_score`, `cross_validate`, `cross_val_predict` |
| `03_pipeline_leakage.py` | 2 | Смещение оценки при предобработке вне процедуры: 0.82 на некоррелированных данных при истинном значении 0.50; +24.7 п.п. на реальных данных. Корректная схема — `Pipeline` |
| `04_model_selection.py` | 2 | `validation_curve`, `GridSearchCV`, сравнение пяти моделей на одних и тех же блоках |
| `05_nested_cv.py` | 2 | Вложенная кросс-валидация: оптимистическое смещение `gs.best_score_` (+1.7 п.п., 22 запуска из 25) |
| `06_manual_example.py` | 3 | Численный пример, LOO, однократное разбиение, сверка с истинным значением и с scikit-learn |
| `07_cv_strategies.py` | 4 | Шесть схем разбиения на одной выборке; `StratifiedKFold` при дисбалансе классов; `GroupKFold` (смещение 23.7 п.п.); `TimeSeriesSplit` (ошибка занижена втрое) |
| `08_choosing_k.py` | 4 | Девять схем оценивания, измеренных относительно известного истинного значения: смещение, стандартное отклонение, RMSE и время |
| `run_all.py` | — | Запускает все скрипты по порядку и пересобирает каталог `figures/` |
| `requirements.txt` | — | Зависимости |
| `figures/` | — | 17 рисунков |

Каждый модуль самодостаточен: запускается отдельно, печатает пояснения и результаты
в консоль и сохраняет свои рисунки в `src/figures/`.

## Запуск кода

```bash
cd src
pip install -r requirements.txt

python run_all.py            # все скрипты по порядку, ~2 минуты
python run_all.py 06         # только численный пример
python 03_pipeline_leakage.py   # или любой скрипт по отдельности
```
