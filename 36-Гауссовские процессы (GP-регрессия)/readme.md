# Гауссовские процессы (GP-регрессия)

Команда 36: Басс Иван, Грищенко Илья, 5030102/30101

## Содержание каталога

- `src/GP_reg.py` - GP-регрессия с подбором гиперпараметров.
  Реализованы три ядра (RBF, Linear, Periodic). Строит график апостериорного среднего с 95%-м
  доверительным интервалом и выводит значение в контрольной точке `x* = 2.3`.

- `src/GP_demo.py` - интерактивная визуализация GP-регрессии.
  Ползунки для гиперпараметров `l`, `σ_f`, `σ_n`, `period` и переключатель
  ядра. В реальном времени показывает апостериорное среднее, доверительную
  полосу, значение `log p(y|θ)`, матрицу `K`, вектор `alpha` и предсказание
  в точке `x* = 0.5`.
  
- `src/requirements.txt` - зависимости.

- `GP_Басс_Грищенко.pdf` - презентация.
